# Petshop Patinhas – Site Institucional

Este repositório contém o site **Petshop Patinhas**, um projeto institucional para um petshop que apresenta serviços, produtos e informações sobre cuidados com pets.  
O site foi construído com **HTML5, CSS3 e JavaScript**, focando em uma experiência visual intuitiva, agradável e responsiva.

🔗 **Acesse o site online:**  
https://luizrogeriopx.github.io/petshop-patinhas/

---

## 🐾 Sobre o projeto

O site funciona como **vitrine digital** para um petshop, exibindo:

- Seção de destaque inicial  
- Produtos e serviços para pets  
- Informações de contato  
- Layout leve, moderno e acessível  

Ele é ideal para clínicas e lojas de animais que desejam uma presença online profissional e funcional.
